# Feature Specification: 大荒斩妖录 Web 应用

**Feature Branch**: `1-web-game`
**Created**: 2025-01-30
**Status**: Draft
**Input**: 基于《山海经》的点击式浏览器游戏应用，包含刀具升级系统、五方地图探索和等级压制战斗机制

## Clarifications

**Session 2025-01-30**

- Q: 刀具升级的具体条件是什么？ → A: 材料合成升级。10级刀使用10级材料+9级材料合成升级为9级刀，9级刀使用9级材料+8级材料合成升级为8级刀
- Q: 刀意值如何恢复？ → A: 刀意值仅在刀等级==怪物等级（同等级战斗）时显示。打低级怪直接秒杀，不触发战斗界面。退出战斗或失败后刀意值直接消失，无需恢复机制
- Q: 游戏范围和内容量？ → A: 本版本只实现前3把刀（10级山铁樵刀、9级青骨短刀、8级庖丁解牛刀），后续8把刀留待后续版本补充
- Q: 玩家快速连续点击时如何处理？ → A: 轻微防抖，每次点击有100ms冷却时间，防止误连点但不影响爽感
- Q: 材料掉落和升级需要多少数量？ → A: 快速升级节奏。每次击杀必掉1-2个材料，升级只需3-5个对应材料（约3-5只怪）
- Q: 同级战斗的伤害数值如何设计？ → A: 玩家每次点击造成10%伤害（10次击败怪物），怪物每次反伤5%（20次玩家失败），确保玩家有优势
- Q: 开场动画播放时长？ → A: 5-8秒动画，玩家可随时点击跳过
- Q: 一键秒杀功能的具体行为？ → A: 开启后仍进入战斗界面，但玩家点击一次怪物即可直接秒杀（有战斗界面体验，但只需一下）

## User Scenarios & Testing *(mandatory)*

### User Story 1 - 初入大荒 (Priority: P1)

玩家首次打开网页应用，看到开场动画"大荒斩妖录"，进入主界面，选择初始区域开始游戏。

**Why this priority**: 这是玩家进入游戏的第一步，没有这个功能游戏无法开始。必须确保玩家能够顺利进入并理解基本界面。

**Independent Test**: 玩家打开浏览器访问应用 → 看到开场动画 → 动画结束后看到五方地图布局 → 可以点击选择区域 → 看到初始刀具（山铁樵刀）和首个怪物

**Acceptance Scenarios**:

1. **Given** 玩家首次访问应用，**When** 页面加载完成，**Then** 显示"大荒斩妖录"开场动画（标题+配图）
2. **Given** 开场动画播放中，**When** 玩家点击跳过按钮或等待动画结束，**Then** 进入主界面并显示五方地图布局
3. **Given** 玩家在主界面，**When** 查看屏幕，**Then** 看到5个相同大小的正方形区域（东、西、南、北、中）排列为地图布局
4. **Given** 玩家点击任意区域，**When** 点击完成，**Then** 进入该区域的二级界面，看到当前可挑战的怪物列表

---

### User Story 2 - 斩妖升级 (Priority: P1)

玩家通过点击怪物进行战斗，收集材料升级刀具，从低级刀逐步进阶到高级神兵。

**Why this priority**: 这是游戏的核心玩法循环。没有战斗和升级系统，游戏就失去了可玩性。

**Independent Test**: 玩家选择区域 → 看到怪物 → 点击怪物攻击 → 根据等级压制规则战斗 → 获得掉落材料 → 使用材料升级刀具

**Acceptance Scenarios**:

1. **Given** 刀等级 < 怪物等级（如10级刀打7级怪），**When** 玩家点击怪物，**Then** 直接触发秒杀效果，无需战斗界面，直接获得掉落物
2. **Given** 刀等级 == 怪物等级（如10级刀打10级怪），**When** 玩家点击怪物，**Then** 进入战斗界面，显示刀意值（血条），每次点击怪物受伤，怪物反伤扣除刀意值
3. **Given** 刀等级 > 怪物等级（如10级刀打1级怪），**When** 玩家点击怪物，**Then** 怪物反伤极高，两次攻击后刀意值归零，战斗失败
4. **Given** 玩家收集足够材料，**When** 在刀具界面点击升级���钮，**Then** 刀具等级提升，刀具图片更新为下一级，播放升级特效
5. **Given** 玩家击败特定怪物，**When** 战斗结束，**Then** 获得对应的材料掉落（如狌狌皮毛、山铁碎片等）

---

### User Story 3 - 神兵图鉴 (Priority: P2)

玩家可以查看已解锁和未解锁的刀具信息，通过边角的小剑图标进入图鉴界面。

**Why this priority**: 这是激励玩家继续游戏的重要动力。让玩家看到还有哪些神兵可以解锁，增加目标感。

**Independent Test**: 玩家点击屏幕边角的小剑图标 → 进入刀具图鉴界面 → 看到本版本3把刀的展示（后续版本预留更多位置）→ 已解锁显示图片，未解锁显示投影

**Acceptance Scenarios**:

1. **Given** 玩家在主界面或战斗界面，**When** 点击边角的小剑图标，**Then** 进入刀具图鉴界面
2. **Given** 玩家在刀具图鉴界面，**When** 查看刀具列表，**Then** 看到本版本3把刀的展示（10级山铁樵刀、9级青骨短刀、8级庖丁解牛刀），预留更多位置显示后续版本刀具
3. **Given** 玩家查看已解锁的刀具，**When** 刀具已解锁，**Then** 显示该刀具的具体图片和名称描述
4. **Given** 玩家查看未解锁的刀具，**When** 刀具未解锁，**Then** 仅显示该刀具的模糊投影/轮廓和"???"名称

---

### User Story 4 - 五方探索 (Priority: P2)

玩家可以在五个区域（东、西、南、北、中）之间切换，每个区域有不同等级的怪物和采集物。

**Why this priority**: 地图切换是游戏进度的重要机制，让玩家能够逐步挑战更强的怪物获得更好的材料。

**Independent Test**: 玩家在区域界面 → 点击问号图标查看该区域的掉落信息 → 返回并切换到其他区域 → 看到不同等级的怪物和采集物

**Acceptance Scenarios**:

1. **Given** 玩家在区域二级界面，**When** 点击右上角问号图标，**Then** 弹出信息面板显示该区域的怪物掉落材料和采集物列表
2. **Given** 玩家查看信息后，**When** 点击关闭或再次点击问号，**Then** 信息面板关闭，返回区域界面
3. **Given** 玩家在一个区域，**When** 点击返回或地图按钮，**Then** 返回五方地图主界面，可以选择其他区域
4. **Given** 玩家切换到不同区域，**When** 进入新区域，**Then** 看到该区域对应的怪物列表（等级范围不同）

---

### User Story 5 - 超脱终局 (Priority: P3) [后续版本]

玩家用1级刀击败所有区域的怪物后，解锁第11把"天刀·无名"，达成超脱结局。

**注意**: 本版本（v1.0）只实现3把刀（10级→9级→8级），此用户故事留待后续完整版本实现。当前版本以8级庖丁解牛刀为最终目标。

**Why this priority**: 这是游戏的终极目标和结局，给予玩家完成游戏的成就感和奖励。

**Independent Test**: 玩家用1级刀击败最终怪物 → 触发超脱动画 → 刀划破Web界面 → 获得第11把天刀无名 → 显示通关画面

**Acceptance Scenarios**:

1. **Given** 玩家用1级刀击败所有区域的怪物，**When** 最后一个怪物被击败，**Then** 触发超脱结局动画
2. **Given** 超脱动画播放，**When** 动画执行，**Then** 刀光划破整个Web界面（DOM分裂效果）
3. **Given** 界面被划破，**When** 裂缝展开，**Then** 露出纯净虚空背景和第11把"天刀·无名"
4. **Given** 结局画面显示，**When** 玩家查看，**Then** 显示通关文字"大荒无极，刀过无痕。你已超脱山海之外。"

---

### Edge Cases

- 玩家刷新浏览器页面时，游戏进度（刀具等级、材料、解锁状态）通过 localStorage 恢复
- 玩家在战斗中刀意值归零后战斗失败，可重新挑战。刀意值退出战斗后直接消失，无需恢复机制
- 玩家快速连续点击时，每次点击有100ms冷却时间，防止误连点
- 浏览器不支持本地存储时的降级处理：显示警告但不阻止游戏
- 图片资源加载失败时的占位显示：使用默认占位图或文字描述

## Requirements *(mandatory)*

### Functional Requirements

- **FR-001**: 系统必须在浏览器中直接可访问，无需安装任何客户端软件
- **FR-002**: 系统必须支持开场动画显示"大荒斩妖录"标题及配图，动画时长5-8秒，玩家可随时点击跳过
- **FR-003**: 系统必须显示五方地图布局，由5个相同大小的正方形实线框组成（东、西、南、北、中），背景使用用户提供的图片填充
- **FR-004**: 系统必须在区域二级界面右上角提供问号图标，点击显示该区域的怪物掉落材料和采集物信息
- **FR-005**: 系统必须在屏幕边角提供小剑图标，点击进入刀具图鉴界面
- **FR-006**: 系统必须在刀具图鉴中显示本版本3把刀，已解锁显示图片，未解锁显示投影。界面预留空间展示后续版本刀具
- **FR-007**: 系统必须实现逆序等级制：10级为最弱，1级为最强
- **FR-008**: 系统必须实现等级压制战斗逻辑：
  - 刀等级 < 怪物等级：触发秒杀，直接获得掉落物
  - 刀等级 == 怪物等级：进入战斗，怪物反伤扣除刀意值
  - 刀等级 > 怪物等级：怪物反伤极高，两次攻击后刀意值归零
- **FR-009**: 系统必须使用刀意值作为玩家血条，仅在刀等级==怪物等级（同等级战斗）时显示，显示为大致百分比（不显示具体数值）。退出战斗或失败后刀意值直接消失
- **FR-009a**: 同级战斗伤害数值：玩家每次点击造成怪物10%伤害（10次击败），怪物每次反伤扣除玩家刀意值5%（20次失败），确保玩家优势
- **FR-010**: 系统必须在怪物受击时将怪物图片变红作为视觉反馈
- **FR-011**: 系统必须支持材料合成升级机制：10级刀使用10级材料+9级材料合成升级为9级刀，9级刀使用9级材料+8级材料合成升级为8级刀。材料可通过怪物掉落或地图采集获得
- **FR-011a**: 系统必须实现快速升级节奏：每次击杀必掉1-2个对应材料，升级需3-5个对应材料（约3-5只怪即可升级）
- **FR-012**: 系统必须实现前3把刀具的完整升级路线（本版本）：10级山铁樵刀（初始）→ 9级青骨短刀 → 8级庖丁解牛刀。后续8把刀（7级-1级+天刀无名）留待后续版本补充
- **FR-013**: 系统必须提供设置界面，包含音量、音效、屏幕抖动效果、一键秒杀效果的开关。一键秒杀开启后，仍进入战斗界面，但玩家点击一次怪物即可直接秒杀（保留战斗体验）
- **FR-014**: 系统必须使用本地存储（localStorage）保存游戏进度，刷新后恢复
- **FR-015**: 系统必须实现点击音效（刀击中怪物）和反伤音效（怪物反击），不同等级刀有不同声音
- **FR-016**: 系统必须实现屏幕抖动和怪物图片抖动的点击反馈效果
- **FR-017**: [后续版本] 系统必须实现超脱结局动画：刀光划破Web界面，露出虚空背景和天刀无名。本版本以8级刀升级完成动画作为版本终点
- **FR-018**: 系统必须在点击时显示伤害飘字效果
- **FR-019**: 系统必须实现轻微防抖机制：每次点击后有100ms冷却时间，防止误连点同时保持爽快感

### Key Entities

- **刀具 (Blade)**: 玩家的主角，本版本包含3个等级：10级山铁樵刀（初始）、9级青骨短刀、8级庖丁解牛刀。每个等级有名称、描述、图片。包含刀意值（血条）属性，仅在同等级战斗时显示
- **怪物 (Monster)**: 分布在五个区域，每个有等级、名称、图片、掉落材料。根据《山海经》异兽设计
- **材料 (Material)**: 怪物掉落和地图采集获得，用于刀具升级
- **区域 (Region)**: 五个区域（东、西、南、北、中），每个有等级范围、怪物列表、采集物列表
- **图鉴 (Collection)**: 记录已解锁的刀具，显示解锁状态

## Success Criteria *(mandatory)*

### Measurable Outcomes

- **SC-001**: 玩家能在打开浏览器后的30秒内开始游戏（开场动画+加载完成）
- **SC-002**: 玩家能在一个游戏会话（5-10分钟）内从初始刀（10级）升级到本版本最终刀（8级）
- **SC-003**: 点击怪物时，视觉反馈（图片变红、抖动）在100毫秒内响应
- **SC-004**: 游戏进度在刷新页面后5秒内完全恢复
- **SC-005**: 玩家能通过刀具图鉴清晰看到已解锁和未解锁的刀具状态
- **SC-006**: 五方地图布局在所有主流浏览器（Chrome、Firefox、Safari、Edge）中正确显示
- **SC-007**: 等级压制战斗逻辑准确执行：秒杀、正常战斗、溃败三种状态正确判定
- **SC-008**: 音效在点击时同步播放，延迟不超过50毫秒

## Assumptions

- 玩家使用现代浏览器（Chrome 90+、Firefox 88+、Safari 14+、Edge 90+）访问应用
- 玩家设备支持音频播放
- 玩家浏览器支持本地存储（localStorage）
- 玩家已准备好刀具图片、地图图片、采集物图片等素材
- 游戏流程设计为5-10分钟完整体验（本版本3把刀），无需长期存档机制
- 刀具使用2D图片通过CSS/JS渲染实现伪3D效果（2.5D），无需真实3D模型
- 点击伤害类游戏，无需复杂的战斗动画，主要通过数值和视觉反馈实现
