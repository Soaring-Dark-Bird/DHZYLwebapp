1.  **选择合适的运行环境**：

    * Cloud Code 允许你在本地模拟云端环境。使用 **"Cloud Run: Run/Debug Locally"** 功能，你可以在本地代码发生变化时自动重新构建并运行，这会大大提高开发效率。

    * 利用 Cloud Code 与 **Secret Manager** 的集成。不要将 API 密钥或数据库密码硬编码在代码中。你可以直接在 IDE 中查看和管理你的 Secret，并将其安全地注入到你的 Web 应用中。

**👉 策略：我们将 2D 刀具图片贴在一个透明的 3D 平面上，让它在太虚空间中漂浮、旋转。**

  * **视觉效果**：看起来就像一把扁平的、具有神性的刀悬浮在空中。配合 SpecKit 的光照和背景粒子，效果会非常有“上古神兵”的感觉。
  * **时间成本**：极低。不需要建模，只需要写代码。

### 1. 祭炼系统（升级 UI）
光有材料是不够的，你需要一个**“祭炼（Forge）”界面**：
* **交互逻辑**：当玩家在地图上收集齐了特定数量的材料（比如 10 个“旋龟壳”），点击一个悬浮的“祭炼”按钮。
* **视觉反馈**：点击祭炼时，3D 刀身剧烈颤抖，发出强光（利用 SpecKit 的光照增强），然后纹理瞬间替换成高一级的 `knife-lv{N-1}.png`。
* **文案提示**：弹出古风文案，如：“凡铁褪尽，灵光乍现，刀已晋升至 [阶段名]”。

### 2. 五方地图切换（大图系统）
你需要一个**“山海舆图”**：
* **核心功能**：一个侧边栏或全屏遮罩层，显示“东、西、南、北、中”五个地标。
* **等级锁定**：
    * 开始只能去“东山经”。
    * 只有刀达到一定等级（比如 7 级），才能解锁“中山经”。
* **背景切换**：切换地图时，背景图片 `map-{region}.png` 和环境音效同步更换。

### 3. 刀意值（血条）的自动恢复与“断刃”
既然没有离线收益，战斗中的生存感就很重要：
* **自动恢复**：非战斗状态下，刀意值每秒回 5%。
* **战斗惩罚**：如果刀意值归零，判定为“刀身受损”，强制玩家在 5 秒内无法点击，且屏幕变灰。
* **紧张感**：当刀意值低于 30% 时，增加一个低沉的“心跳声” `.mp3` 循环。

### 4. 掉落物浮窗（Loots Pop-up）
点击类游戏最爽的就是“获得感”：
* **视觉效果**：每当触发【碾压】秒杀怪物时，屏幕上怪物消失的位置，随机向四周飞出材料小图标，并自动吸入左下角的背包图标里。
* **文字流**：屏幕右侧滚动显示：“获得 狌狌之毛 x1”、“获得 妖丹 x1”。

### 5. “万物志”或任务引导（简易版）
因为流程只有 20 分钟，玩家需要知道“接下来干什么”：
* **小贴士**：在 UI 角落放一个半透明的卷轴，提示：“当前目标：击杀 [XX] 获取 [XX] 以突破至第 8 级”。
* **怪物图鉴**：击败某种怪物后，可以在图鉴里看到它的简短《山海经》原句介绍。

### 6. 最终的“太虚”仪式感
对于 Level 11 的超脱，我们需要在代码里预留一个**“终局逻辑”**：
* **全屏粉碎**：当 1 级刀砍死最终 Boss 后，禁用所有 UI。
* **震动与白光**：利用浏览器 `navigator.vibrate`（如果是移动端）和 CSS `filter: brightness(5)`。
* **结局文字**：在虚空中缓缓浮现：“大荒无极，刀过无痕。你已超脱山海之外。”
